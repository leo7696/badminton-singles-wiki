羽球單打基礎戰術與步法入門

給第一次接觸單打的你：從看懂「窄而長」的場地界線開始，建立「啟動 → 移動 → 回中」的步法習慣，最後學會用拉吊與節奏掌控比賽。

01 / 學習地圖

新手學單打，只要先抓這 3 件事

  • 1. 空間觀念（界線與站位）先分清楚單打有效範圍，並養成打完球回到「中心站位」的習慣。
  • 2. 移動節奏（啟動步與回動）跑得快不如「啟動得準」，學會用完整步法迴圈省下體力。
  • 3. 戰術思維（先拉吊、再突擊）單打不是有球就殺，懂得調動對手重心，機會才會自然出現。
教學結構總覽 Ref: README.md
02 / 場地規則

單打界線口訣：「窄而長」

  • 左右看內線雙打會用到最外側邊線，但單打只算內側邊線以內。
  • 前後看最外底線無論發球還是對打，後場都算到最外側底線。
  • 新手常見誤判剛從雙打轉單打時，最常把「外側邊線」當界內，或發球時誤以為後場長線出界。
綠色區域為單打對打有效範圍

03 / 中心站位

為什麼每打完一球都要「回中」？

  • 一個人守全場沒有隊友補位，站在角落等於把另外三個角落拱手讓人。
  • 位置在哪裡？場地正中央稍微偏後半步，兼顧前場撲救與後場退防。
  • 常見錯誤打完球留在原地「欣賞自己的球路」，等對手回球才開始跑。
  • 正確心態回中不是站死在某一點，而是回到「用最少步數覆蓋四個角落」的平衡點。
防守覆蓋原則 Ref: concepts/base-and-boundaries.md
04 / 步法架構

單打步法是一個「閉環」，不是單程票

1. 中心站位
→
2. 啟動步
→
3. 墊步與推蹬
→
4. 擊球
→
5. 反推回動
  • 前場煞車細節最後一步跨出時腳跟先著地、膝蓋不超過腳尖，既保護膝蓋，又能順勢反推回位。
  • 核心觀念「擊球」只是這趟移動的中點，安全回到中心站位才算完成一拍。

05 / 啟動步 Split Step

快人一步的秘密：在對手擊球瞬間「微跳壓低」

  • 什麼是啟動步？對手擊球瞬間，雙腳微幅離地並向兩側分開落地，同時膝蓋微彎壓低重心。
  • 為什麼有效？就像彈簧先壓縮再彈出，讓往四個角落踏出的第一步爆發力最大化。
運動學研究數據：
高水準選手多在對手擊球後約 14～36 毫秒內完成離地啟動，雙腳落地瞬間剛好判斷出球路方向，直接蹬地出發。

新手練習口訣：對手一揮拍，你就「小跳一下、重心沉下去」，不要直挺挺站著等球。

啟動時機與爆發力 Ref: concepts/footwork-loop.md, sources/02
06 / 戰術觀念

新手最大迷思：單打不是「有球就殺」

  • 盲目殺球的代價每拍都全力殺球，體力半局就見底。
  • 更容易陷入被動殺球沒殺死時，自己重心向前衝，對手只要輕輕挑到後場，你就會完全來不及退防。
單打核心思維：
先用高遠球與吊球（切球）讓對手前後奔跑，等對手體力下降、回出「不夠深的半場球」時，再一拍突擊得分。
打破錯誤觀念 Ref: concepts/singles-tactics.md
07 / 戰術三階段

實戰節奏：拉吊消耗 → 被動過渡 → 抓時機突擊

比賽階段 常用球路 戰術目的
1. 建立優勢（拉吊） 高遠球、吊球（切球）、四角球 迫使對手前後左右折返跑，消耗體力並破壞重心。
2. 被動自救（過渡） 高遠球、挑高球、擋網 處於劣勢時絕不硬殺，把球打深打高替自己爭取回中時間。
3. 終結得分（突擊） 殺球 + 上網撲球、快拉快吊 趁對手回球不到位（半場球）或重心後退時，突然加速得分。
攻守轉換邏輯 Ref: concepts/singles-tactics.md
08 / 打法速查

單打五大基本打法

  • 1. 控後場壓底用高遠球把對手壓在底線，爭取自己的回防與觀察時間。
  • 2. 打四角球輪流攻擊前左、前右、後左、後右四個角落，拉開對手跑動距離。
  • 3. 殺上網後場重殺後立刻跟進網前，準備撲球或放網終結。
  • 4. 快拉快吊用平高球與快速切球加快節奏，打亂對手步法。
  • 5. 守中反攻先穩穩防守過渡，等對手進攻失誤或體力下滑再反擊。
經典戰術分類 Ref: sources/04-basic-shots-and-tactics.md
09 / 總結與練習

下次上場，先做好這 3 件事就夠了

  • Check 1打完每一拍，強迫自己立刻回到「中心偏後半步」。
  • Check 2對手揮拍瞬間做一次「啟動步」，膝蓋微彎不要站直。
  • Check 3被動時乖乖打高遠球過渡，等到對手回球變淺再進攻。
