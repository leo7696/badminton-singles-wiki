# 03. 前場腳步詳解與回動訓練

- **來源**：傳羽運動網
- **網址**：https://www.chuanyusport.com.tw/Article/%E5%89%8D%E5%A0%B4%E8%85%B3%E6%AD%A5%E8%A9%B3%E8%A7%A3%E8%88%87%E8%A8%93%E7%B7%B4%E6%B3%95%EF%BC%8C%E6%9C%89%E6%95%88%E6%8F%90%E5%8D%87%E5%89%8D%E6%8E%92%E7%A7%BB%E5%8B%95%E8%83%BD%E5%8A%9B
- **關聯概念**：[[footwork-loop]]、[[base-and-boundaries]]

## 核心重點
1. **完整步法五階段**：啟動 → 墊步 → 推蹬跨步 → 擊球 → **回動（回中）**。
2. **最後一步煞車**：前場跨步時腳跟先著地、膝蓋不超過腳尖，保護關節並利於反推回位。
3. **新手盲點**：多數新手打完球會「原地欣賞球路」，忽略擊球後立刻推蹬回中心站位，導致下一拍來不及接。
