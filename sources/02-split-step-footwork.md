# 02. 羽球單打四角球啟動步之運動學分析

## 核心重點
1. **啟動步（Split Step）定義**：在對手擊球瞬間，雙腳微幅離地並向兩側分開落地，利用下肢伸展—收縮循環（SSC）產生爆發力。
2. **離地時機**：研究顯示優秀選手多在對手擊球後約 **14～36 毫秒**內完成離地啟動，落地時剛好判斷出球路方向。
3. **重心控制**：啟動時膝蓋微彎、壓低重心，避免直立站姿導致第一步蹬地過慢。
