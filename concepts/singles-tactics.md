# 概念：單打五大打法與節奏控制

> **資料來源**：`sources/04-basic-shots-and-tactics.md`、`sources/05-rally-and-tempo.md`

## 新手最容易搞錯的事
單打不是「有球就殺」。盲目殺球不只耗體力，一旦沒殺死，自己重心在前、對手一挑後場就會陷入極度被動。

## 核心戰術邏輯：先拉吊，再突擊
| 階段 | 使用球路 | 戰術目的 |
| :--- | :--- | :--- |
| **建立優勢（拉吊）** | 高遠球、吊球（切球）、打四角 | 讓對手前後左右奔跑，破壞其重心與體能 |
| **被動自救（過渡）** | 高遠球、挑高球、擋網 | 爭取時間回到中心站位，絕不硬殺 |
| **終結得分（突擊）** | 殺球 + 上網撲球、快拉快吊 | 趁對手回球不到位（半場球）時加速得分 |
